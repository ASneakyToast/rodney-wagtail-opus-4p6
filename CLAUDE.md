# Rodney Wagtail Automation

## Automatic Startup (Claude Code on the web)

When a session starts, the SessionStart hook installs all dependencies (jq, Chrome, uv, rodney, showboat) and writes the `.env` file. **You should immediately begin the automation pipeline without waiting for user input.**

## Pipeline — Run These Steps In Order

### Phase 1: Discovery

Run the discovery phase to explore the Wagtail admin and auto-generate CSS selectors:

```bash
bash discovery/run-all.sh
```

This logs into the Wagtail admin, explores the page tree, discovers form fields and StreamField block types, and writes updated selectors to `config/selectors.sh`.

If discovery fails on a specific step, diagnose the issue from the output and screenshots, fix it, and retry that step individually (e.g., `bash discovery/03-inspect-page-form.sh`).

### Phase 2: Content Creation

Run the content creation phase to create and publish a new page:

```bash
bash create/run-all.sh
```

This creates a new "Design Strategy MBA" page under the configured parent, fills all sections from `data/design-strategy-mba.json`, and publishes it.

If a step fails, check the screenshot in `screenshots/` for context. You can restart from a specific step (e.g., `bash create/05-fill-overview.sh`), but note that the browser session must still be active.

### Phase 3: Verification

Run verification scripts to confirm the page was created correctly:

```bash
bash verify/verify-creation.sh
bash verify/verify-content.sh
bash verify/verify-published.sh
```

These generate Showboat markdown documents in `docs/` and screenshots proving the page exists, content matches, and the page is live.

## Troubleshooting

- **Browser not started**: Run `uvx rodney start` to start headless Chrome.
- **Login fails**: Check `.env` credentials. The login page is at `${WAGTAIL_ADMIN_URL}/login/`.
- **Selector not found**: Re-run discovery phase — Wagtail may have updated its DOM structure.
- **StreamField block fails**: Check `screenshots/` for the latest state. The block chooser UI varies between Wagtail versions.
- **Step partially completed**: Check `uvx rodney url` to see current page state and `uvx rodney screenshot debug.png` to capture what the browser sees.

## Key Files

| Path | Purpose |
|------|---------|
| `config/env.sh` | Loads and validates `.env` variables |
| `config/selectors.sh` | CSS selectors (auto-generated by discovery) |
| `lib/*.sh` | Reusable helper functions |
| `data/design-strategy-mba.json` | Content data for the page |
| `discovery/run-all.sh` | Full discovery pipeline |
| `create/run-all.sh` | Full creation pipeline |
| `verify/*.sh` | Verification scripts |
